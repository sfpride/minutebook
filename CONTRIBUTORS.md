## Adding Your Key

1. Generate a GPG key (see [SIGNING.md](SIGNING.md))
2. Submit your public key fingerprint to the Secretary
3. Add your public key to GitHub: Settings → SSH and GPG keys
4. You'll be added to this table once verified

## Verifying Keys

Public keys for all signers are available on:
- [keys.opengpg.org](https://keys.openpgp.org)
- GitHub user profiles

To import a key locally:
```bash
gpg --keyserver keys.openpgp.org --recv-keys <FINGERPRINT>
```
